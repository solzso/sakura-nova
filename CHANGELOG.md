## [1.0.0] - 2026-09-21

First public release.

### Added

- **Sakura Nova Dark** — the default variant. Violet keywords, mint strings, `#100E23` canvas.
- **Sakura Nova Dark Pro** — higher-contrast take with pink keywords and cooler variables.
- **Sakura Nova Warm** — softer plum `#231A2D` background for long sessions.
- **Sakura Nova Dark Red** — rose-forward accents with italic variables and properties.
- **Sakura Nova Light** — daylight variant tuned for contrast over pastel wash.
- Semantic highlighting for every variant (`semanticHighlighting: true` plus per-variant `semanticTokenColors`).
- Bracket pair colorization: three nesting levels plus an unexpected-bracket color.
- Full 16-color ANSI terminal palette per variant.
- Tuned token rules for JavaScript, TypeScript, JSX/TSX, HTML, CSS/SCSS, Python, C, C++,
  Rust, Go, Java, Ruby, PHP, Swift, Markdown, JSON/JSONC, YAML, TOML and Shell.
- Shared `#FF5DA2` accent across all five variants, so switching keeps the UI chrome consistent.
